# The Magnet's Straight or Triplet belongs to the Pattern

Whether the Magnet is Straight (8 Divisions) or Triplet (12) is part of the Pattern and travels in the URL, even though it changes nothing that is heard: every Voice already carries its exact angle. We chose this so that whoever opens a shared link, reloads or goes back keeps editing on the same Divisions the Pattern was built on. Off stays out of the Pattern, as in v1: it is a per-session choice, and while off the Pattern keeps the last of Straight or Triplet.

## Considered Options

- **Keep the mode out of the URL, like the Magnet's on/off**: rejected; a triplet Pattern opened from a link would snap new Voices to 8 Divisions and fight what is already there.

## Consequences

- Two links that differ only in this field are different Patterns that sound the same.
- It needs the v2 codec; Straight is the default and is not written, so links without other new fields stay `v1`.
